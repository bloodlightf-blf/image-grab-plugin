为什么需要「图提取」

电商详情页图片通常分散在多个懒加载节点中，手动另存效率低、格式也不统一。

🧩

图片分散难找

商品图藏在 srcset、data-src 与背景图中，一张张另存非常麻烦。

📥

无法批量保存

浏览器原生只能单张另存，大量图片时重复操作费时费力。

🎨

格式不统一

jpg、webp 混在一起，下载后还要二次转换才能统一使用。

核心功能

从提取到下载，六步全自动。

⚡

一键提取

详情页右下角点击「获取图片」，自动扫描整页商品图。

🧹

智能过滤

自动剔除图标、logo、占位图与小于 100×100 的小图。

🖼️

集中预览

新标签页网格化展示，缩略图与尺寸一目了然。

☑️

自由勾选

支持全选、反选，只下载你需要的那几张。

🔄

统一 PNG

jpg / webp 通过 canvas 自动转换为 PNG 格式。

📦

批量下载

自动命名「商品图_001.png」，一次下载多张。

三步安装，立即使用

无需打包、无需开发者账号，本地加载即可。

  1. 1

    下载并解压

    下载插件压缩包，解压到本地文件夹（如 D:\image-grab-plugin）。

  2. 2

    打开扩展页

    打开 Chrome，地址栏输入 chrome://extensions 并回车。

  3. 3

    开启开发者模式

    打开页面右上角的「开发者模式」开关。

  4. 4

    加载已解压的扩展

    点击「加载已解压的扩展程序」，选择解压后的文件夹即可完成安装。
